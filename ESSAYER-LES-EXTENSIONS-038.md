# Les en-têtes deviennent une extension — 0.0.38

**En-têtes des fiches** décide maintenant du titre affiché et des petites informations au-dessus des commandes : type de média, présence dans la collection, année, durée, genres, note, accroche et édition musicale. Le thème garde la main sur leur apparence.

## Vérifier simplement

1. Ouvrez la fiche d’un film, d’une série ou d’un album : son en-tête habituel est conservé.
2. Dans Réglages → Extensions → En-têtes des fiches, désactivez l’extension, puis rouvrez la fiche.
3. Le titre simple et les commandes restent accessibles ; les informations enrichies sont remplacées par une explication. Rien n’est effacé.
4. Réactivez l’extension : l’en-tête revient sans scan.

## Essayer une autre présentation

Dans les artefacts GitHub Actions, récupérez example-detailheader.mosaune.zip, puis importez-le dans Mosaune. Activez **Dans le cadre — exemple**, puis **Utiliser pour les fiches**. L’en-tête devient minimal, avec l’accroche « Une autre façon de présenter votre collection. » Les résumés et saisons restent gérés par leurs propres extensions.

Pour revenir à la présentation habituelle, sélectionnez **En-têtes des fiches**. Activer un module ne remplace pas le choix existant.

[Contrat contributeur](extension-kit/capabilities/detailheader/v1/README.md) · [Exemple indépendant](extension-kit/examples/detailheader)

Cette étape concerne les textes de l’en-tête. Les affiches, liens d’artistes, commandes, suggestions et listes musicales restent à découper. Les lecteurs personnalisés et le déploiement NAS viennent ensuite.
