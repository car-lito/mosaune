# Paquet TMDB et découverte — 0.0.52

Cette étape concerne le découpage interne. L'apparence habituelle ne change pas et aucune manipulation de vos médias n'est nécessaire.

Sur une installation existante : arrêter votre ancien serveur puis lancer DEMARRER-WINDOWS.cmd. Dans Réglages → Extensions → À télécharger, TMDB 0.6.0 est proposé ; installer sa mise à jour depuis sa fiche. Vos identifiants et vos choix d'activation restent conservés. Une installation neuve reçoit directement ce paquet.

Vérification visuelle facultative : après la mise à jour, rechercher un film et vérifier que les résultats habituels apparaissent ; désactiver TMDB et vérifier que la découverte des films s'arrête tandis que votre collection reste accessible. La musique peut toujours proposer des résultats via MusicBrainz.

Les contrôles automatiques couvrent aussi des paquets de test déclarant volontairement moins de fonctions, le retour à la version précédente, la désinstallation, le redémarrage et le refus d'appels non déclarés. Ces paquets de test ne sont pas distribués.

Les anciennes archives ne sont pas modifiées. Aucune nouvelle extension visible n'est ajoutée. Le serveur conserve encore du code spécifique aux fournisseurs : cette étape ne clôt pas le découpage complet.
