# Lecture directe

Exemple autonome de media.detail-experience.v1. Le programme n’importe ni le serveur ni les règles officielles. Il affiche les fichiers autorisés avec une seule commande de lecture et choisit une pochette carrée. Il ne modifie aucune donnée.

Construire avec la commande de construction du projet, puis importer build/example-detailexperience.mosaune.zip dans Réglages → Extensions. Activer puis sélectionner « Lecture directe ». Pour revenir, sélectionner « Comportements des fiches » officiel. Retirer l’exemple ne choisit pas automatiquement un autre module.

Pour un dépôt GitHub, publier l’archive avec un index mosaune-repository.json : kind = detail-experience, id/version/minCore identiques au manifeste, path vers l’archive, sha256 de l’archive. Même procédure de publication que les autres modules ; aucun accès supplémentaire n’est accordé par l’ajout d’un dépôt.
