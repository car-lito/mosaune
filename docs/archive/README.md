# Archives documentaires

Ces documents ont été conservés pour expliquer les versions passées, leurs essais et les raisons des migrations. Ils **ne constituent pas la roadmap actuelle**.

- `versions/` : guides d’essai historiques, parfois liés à des versions ou binaires anciens.
- `EXTENSION-PROGRESS-0084.md` : ancienne estimation et checklist ; les pourcentages étaient indicatifs.
- `PRE-NAS-PLAN-LEGACY.md` : ancien plan accumulant plusieurs étapes, remplacé par la roadmap globale.
- `PLAYER-EARLY-DESIGN.md` : première ébauche, remplacée par les décisions détaillées des lecteurs.

Pour reprendre : [état réel](../STATUS.md), [roadmap](../ROADMAP.md), [décisions](../product/DECISIONS.md), [construction](../development/BUILD.md).

Les lanceurs qui pointaient vers des binaires figés ont été remplacés par un lancement suivant `package.json`. Le lanceur de laboratoire non construit par le pipeline courant a été supprimé. Les migrations et paquets signés de compatibilité sont conservés ; ils ne deviennent pas obsolètes simplement parce qu’un ancien guide les cite.
