# Catalogue Mosaune — préversion CasaOS 0.4.x

Préparation destinée à CasaOS 0.4.15. La compatibilité des fichiers est vérifiée avec Docker Compose ; l'import dans cette version de CasaOS et l'exécution sur le NAS restent à tester.

Ce catalogue n'installe rien par lui-même. La première installation nécessite une adresse HTTPS, des certificats reconnus par les appareils et des dossiers aux bons droits. L'application refuse de démarrer si ces éléments manquent.

Guide : https://github.com/car-lito/mosaune/blob/main/deploy/README.md

Ne pas utiliser une base Windows directement sur le NAS : les chemins des médias doivent d'abord être migrés.
